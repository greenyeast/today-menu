# 오늘의 학식 (today-menu)

학교 식당의 날짜별 식단을 조회하고 등록·수정·삭제할 수 있는 체험용 웹 서비스입니다. 학생용 조회 화면과 메뉴 관리 화면을 제공하며, 별도의 서버나 데이터베이스 없이 브라우저에 식단을 저장합니다.

## 주요 기능

- **식단 조회**: 선택한 날짜의 조식·중식·석식, 메뉴 구성, 가격, 알레르기 안내를 확인합니다.
- **날짜 이동**: 날짜 선택과 이전 날·오늘·다음 날 버튼으로 조회 날짜를 변경합니다.
- **식단 관리**: 식단을 등록·수정·삭제하고, 날짜와 식사 구분으로 목록을 필터링합니다.
- **입력 검증**: 필수 입력값과 가격을 검증하고, 같은 날짜·식사 구분의 중복 등록을 방지합니다.
- **데모 데이터**: 최초 이용 시 샘플 식단을 생성하며, 메뉴 관리 화면에서 초기화할 수 있습니다.
- **반응형 화면**: 화면 크기에 따라 배치를 조정하고 키보드 포커스와 오류 안내를 제공합니다.

## 기술 구성

| 기술 | 용도 |
| --- | --- |
| HTML, CSS, JavaScript | 페이지 구조, 스타일, 동작 구현 |
| React 18, ReactDOM 18 | 컴포넌트 렌더링과 상태 관리 |
| Tailwind CSS | 유틸리티 클래스 기반 스타일링 |
| Babel Standalone | 브라우저에서 JSX 변환 |
| Lucide | 화면 아이콘 표시 |
| localStorage | 브라우저에 식단 데이터 저장 |

외부 라이브러리는 CDN으로 불러옵니다. `package.json`이나 별도의 빌드 설정은 없으며, 각 HTML 파일에 스타일 설정과 React 코드가 포함되어 있습니다.

## 파일 구조

```text
today-menu/
├── index.html       # 서비스 소개 및 학생 보기·메뉴 관리 진입 화면
├── student.html     # 날짜별 식단 조회 화면
├── menumanage.html  # 식단 등록·수정·삭제 및 필터 화면
├── .gitignore       # Git 추적 제외 설정
└── README.md        # 프로젝트 안내
```

각 페이지는 상대 경로 링크로 연결됩니다. 식단 조회·관리 페이지의 날짜 처리, 샘플 생성, 데이터 검증 로직은 각 파일 내부에 정의되어 있습니다.

## 실행 방법

JavaScript와 localStorage를 사용할 수 있는 최신 브라우저 및 인터넷 연결이 필요합니다. CDN에서 라이브러리를 불러오므로 인터넷 연결이 없으면 화면이 정상적으로 표시되지 않을 수 있습니다.

Python 3가 설치되어 있다면 프로젝트 루트에서 다음 명령으로 정적 서버를 실행합니다.

```bash
python3 -m http.server 8000
```

브라우저에서 아래 주소로 접속합니다.

- 홈: <http://localhost:8000/>
- 학생 보기: <http://localhost:8000/student.html>
- 메뉴 관리: <http://localhost:8000/menumanage.html>

학생 보기와 메뉴 관리가 같은 저장소를 사용하도록 동일한 호스트와 포트로 접속합니다.

## 사용 방법

1. 홈에서 **학생 보기**로 이동해 날짜별 식단을 확인합니다. 저장된 데이터가 없는 상태에서 학생 보기 또는 메뉴 관리에 처음 접속하면, 접속일 기준 오늘의 세 끼와 다음 날 중식 샘플이 생성됩니다.
2. **메뉴 관리**에서 식단 등록 버튼을 누르고 제공 날짜, 식사 구분, 대표 메뉴명, 메뉴 구성, 가격을 입력합니다. 알레르기 안내는 선택 항목입니다.
3. 메뉴 구성은 한 줄에 한 항목씩 입력합니다. 대표 메뉴명은 앞뒤 공백 제거 후 1~100자, 가격은 0 이상의 정수여야 합니다. 0원은 무료로 표시됩니다.
4. 목록에서 식단을 수정하거나 삭제하고, 날짜·식사 구분 필터로 원하는 항목을 찾습니다. 같은 날짜의 같은 식사 구분에는 한 건만 등록할 수 있습니다.
5. 학생 보기로 돌아가 저장한 식단을 확인합니다.

## 데이터 저장 및 이용 범위

- 식단은 `school-meals-demo-v1` 키로 localStorage에 JSON 배열 형태로 저장됩니다. 각 항목에는 식별자, 날짜, 식사 구분, 대표 메뉴명, 메뉴 구성, 가격, 알레르기 안내, 생성·수정 시각이 포함됩니다.
- 같은 브라우저 프로필과 출처(프로토콜·호스트·포트)에서 저장된 데이터를 공유합니다. 다른 브라우저나 기기와는 공유되지 않으며, 사이트 데이터를 삭제하면 식단도 삭제됩니다.
- 메뉴 관리 화면에는 로그인이나 관리자 인증이 없습니다. 실제 학교 식단 시스템과 연동되지 않는 체험용 서비스입니다.
- **데모 데이터 초기화**는 기존 식단을 삭제하고 초기화 시점의 날짜를 기준으로 샘플 식단을 다시 생성합니다.
- 저장된 데이터 형식이 올바르지 않으면 경고를 표시하고 메뉴 관리의 등록·수정·삭제를 제한합니다. 필요한 원본 데이터는 브라우저 개발자 도구에서 보관한 뒤 초기화할 수 있습니다.
- 샘플 식단과 알레르기 정보는 데모 예시이며, 실제 식사 전에는 식당의 안내를 확인해야 합니다.
